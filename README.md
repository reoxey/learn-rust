# Learn Rust, a little every day

A fundamentals-first path for a programmer with Go/backend experience. Spend **15–20 minutes a day** on one small exercise, record what you learned, and commit your own work. Eight weeks is a suggested sequence; repeat days freely. The goal is to build and explain small Rust programs independently, then progress into practical CLI and networking work.

## The path

| Week | Focus | Output |
| --- | --- | --- |
| 1 | Syntax, functions, control flow | Temperature table |
| 2 | Ownership, borrowing, slices | Borrowed text report |
| 3 | Structs, enums, Option, collections | In-memory task summary |
| 4 | Result, lifetimes, modules, tests, traits | Tested task module |
| 5 | CLI arguments, files, errors | Word-count CLI |
| 6 | Iterators, closures, threads, channels, shared state | Small concurrency examples |
| 7 | Local TCP input/output | Bounded line-based service |
| 8 | Independent application of the fundamentals | A small capstone CLI |
